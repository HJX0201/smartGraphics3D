# AIS 共享显示实例：设计、实现与对比验证

## 结论

smartGraphics3D 同时保留两种复制：

- 普通复制：共享 `SKernelShape` 的基础拓扑，但每个对象建立独立 `AIS_Shape`
  Presentation 和显示几何。
- 共享显示实例：相同几何与显示属性使用一个未显示 `AIS_Shape` 原型，每个对象建立
  `AIS_ConnectedInteractive` 并保存独立变换和选择 Owner。

方案在 OCCT 7.7.0 下可行。正式压力测试不是复制成百上千个小对象，而是先生成一个包含
5000 个实体、约 234.24 万显示三角形的单一大模型，再只复制 1、2、5、10 份。10 份时
Private Bytes 减少 74.37%，估算 GPU 几何从 1876.50 MiB 降到 187.65 MiB，减少 90%。

内存并不会固定减半。2、5、10 份时可共享 GPU 几何的理论减少分别是 50%、80%、90%；
进程总内存还包括拓扑、Qt、OCCT、选择、变换和每实例连接结构，所以降低比例更小。

## 数据模型

`SCopyMode` 包含：

- `IndependentPresentation`：普通复制，新建 `presentation_group_id`。
- `SharedPresentation`：实例复制，继承源对象的显示组 ID。

所有可渲染对象具有非空显示组 ID。批量复制和阵列在一个文档事务中提交。平移、旋转只
更新对象变换并保持共享；缩放、布尔、圆角、倒角、孔、镜像等先通过统一入口物化场景
几何，再产生单位变换和新显示组的独立结果。

`.sg3d` 使用格式版本 3 和 Magic `SGRAPH3D`。保存、加载、快照、撤销/重做均保留显示
组与变换。加载同组对象时校验序列化 BREP；几何不一致按损坏数据拒绝。旧版扩展名和
旧 Magic 明确拒绝，不执行迁移。

## AIS 生命周期与选择

渲染键由显示组 ID、颜色、透明度和显示模式组成：

- 可见成员只有一个时退化为独立 `AIS_Shape`。
- 两个以上成员建立一个原型和 N 个 Connected 实例。
- 属性不同自动拆组；隐藏、冻结、删除保持对象级语义。
- 清理时先 Disconnect 并移除实例，最后释放原型。

选择先定位具体 Connected 实例，再使用底层 `TShape/IsPartner` 映射原型子形状，避免
实例 Location 使面、边、点索引失效。`SRenderResourceStatistics` 提供独立
Presentation、共享原型、Connected 实例、结构、展开三角形、GPU 估算和 OCCT 原始统计，
公共接口不暴露 OCCT 类型。

## 固定网格基准

大 Compound 在普通应用中会触发交互式渐进质量。若普通和共享模式使用不同的网格质量，
内存对比没有意义。因此视口提供无 OCC 类型的
`setProgressiveRenderingEnabled(false)`，仅由基准调用，确保两种模式都使用 BREP 中
相同的固定网格；应用默认仍启用渐进质量。

## 功能与发布验证

自动测试覆盖普通/实例复制组 ID、多选和阵列、移动/旋转保持共享、缩放和几何编辑物化、
对象及子形状选择、颜色/隐藏/冻结/删除、撤销/重做、保存重开、损坏显示组和旧格式拒绝。
结构硬门槛验证普通模式产生 N 个独立 Presentation，共享模式产生一个原型和 N 个
Connected 实例。

## 限制

- 显示属性不同会拆分共享原型。
- 单个可见成员退化为独立 Presentation，所以复制 1 份没有节省。
- 每实例选择 Owner、变换、业务对象和连接结构仍线性增长。
- 大量实例随后被缩放或几何编辑后，内存会逐步接近普通模式。
- 性能受显卡、驱动、窗口曝光和系统负载影响，不应将本机毫秒数作为跨机器硬门槛。
