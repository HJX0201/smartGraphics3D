# smartGraphics3D 使用说明

## 启动与文件

运行发布目录中的 `smartGraphics3D.exe`。程序旁必须保留部署脚本生成的 Qt DLL、
`platforms/qwindows.dll` 和 OCCT DLL。项目文件仅使用 `.sg3d`；旧版扩展名和旧 Magic
不会读取或迁移。

可从“文件”页导入 STEP、IGES、BREP、STL 或 OBJ。导入对象默认保留为原始引用；编辑
操作创建派生结果。保存项目会记录几何缓存、场景对象、变换、显示组和视图状态。

## 基本交互

- 中键拖动：旋转。
- `Shift + 中键`：平移。
- 滚轮：以指针位置缩放。
- `Ctrl + 左键`：多选。
- `Shift + 左键拖动`：框选。
- `Ctrl + K`：聚焦命令输入框。
- `Ctrl + Z` / `Ctrl + Y`：撤销/重做。
- “视图 → 辅助显示 → 显示网格”：显示或隐藏世界 XY 平面的矩形网格；该状态对全部
  视口生效，重新启动软件后恢复为默认显示。

修改操作先显示预览，确认后通过一次文档事务提交。

## 两种复制

- 普通复制 `Ctrl+D`：共享基础拓扑，但每个对象建立独立显示 Presentation。适合随后
  单独改色、缩放或几何编辑的对象。
- 实例复制 `Ctrl+Shift+D`：共享基础拓扑和显示原型。适合大量相同零件摆放和阵列。

共享实例可以独立移动和旋转，并保持显示共享。缩放、布尔、圆角、倒角、孔和镜像等会
先物化场景几何，再生成独立显示组。颜色、透明度或显示模式不一致时，渲染器也会自动
拆分显示原型，以保证结果正确。

线性阵列和圆周阵列可在参数中选择“普通副本”或“共享显示实例”，默认保持普通副本。
属性区域会显示对象当前是“独立显示”还是“共享实例”。

## 诊断与恢复

程序异常退出后可从自动恢复入口恢复上次快照。诊断包使用 `.sgdiag` 扩展名，不应公开
上传包含私有模型或本机路径的诊断文件。损坏、错误 Magic 或不支持版本的项目会被拒绝，
不会尝试部分覆盖当前文档。
