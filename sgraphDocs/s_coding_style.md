# smartGraphics3D 代码规范

## 命名

- 自研目录使用 `smart` 加小驼峰，例如 `sgraphKernel`。
- 自研文件使用 `s_` 加小写下划线，例如 `s_kernel_service.cpp`。
- 类、结构体、枚举和类型别名使用大写 `S` 前缀；接口使用 `SI` 前缀。
- 函数使用小驼峰，局部变量和参数使用小写下划线。
- 私有成员使用 `m_` 加小写下划线。
- 常量使用 `kPascalCase`；宏使用 `SMARTGRAPHICS3D_UPPER_SNAKE_CASE`。

## C++ 与 Qt

- C++17、4 空格、UTF-8、LF、100 列、Allman 大括号。
- 每个自研 `.h`、`.cpp` 不得超过 800 行，约 700 行时按职责拆分。
- 单参数构造函数必须 `explicit`，重写函数必须 `override`。
- 非 QObject 默认使用值语义、`std::unique_ptr` 或 `std::shared_ptr`。
- QObject 使用父子所有权；跨生命周期弱引用使用 `QPointer`。
- 信号槽使用函数指针语法，禁止字符串形式 `SIGNAL`/`SLOT`。
- 头文件不得使用 `using namespace`，且必须可独立编译。
- OCCT 类型仅存在于内核、渲染、格式适配实现，不进入文档和 GUI 公共接口。
- 公共 API 不传播异常，使用 `SResult<T>`。
- 注释解释原因、精度、所有权和失败约束，不复述代码。

## 数据安全

- 原始导入对象默认只读；修改操作默认创建派生对象。
- 所有文档变更通过事务提交，失败和取消不得产生半成品。
- 项目保存使用临时文件和原子替换；自动恢复文件不得静默覆盖正式项目。
- 日志和诊断包默认不得包含模型内容或客户路径中的敏感数据。
